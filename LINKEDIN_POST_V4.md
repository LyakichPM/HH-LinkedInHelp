# ВАРИАНТ 4: «AI в поиске работы — не для спама, а для прецизии» (впечатляет HR, помогает людям)

---

За 3 недели я не просто «автоматизировал отклики». Я построил систему, которая **думает как рекрутер, пишет как кандидат и верифицирует как QA**.

**Репозиторий:** https://github.com/LyakichPM/HH-LinkedInHelp

---

## 🎯 Для HR: мы можем упростить и вам жизнь

Сейчас: 300 откликов на вакансию → 290 без сопроводительного → 9 с шаблоном «Уважаемый HR, мне интересна ваша вакансия» → 1 релевантный.

С этим инструментом:
- Кандидат **не может** отправить пустой отклик (жёсткое правило в коде: `assert cover_letter, "Empty cover letter not allowed"`)
- Каждое письмо **генерируется под конкретную вакансию**: стек, домен, уровень, ключевые метрики компании
- HR видит сразу: «Этот человек прочитал описание, понимает нашу боль, имеет релевантный опыт»
- В чате hh.ru (chatik.hh.ru) письмо прилетает **первым сообщением** — не нужно искать вложения

**Результат для HR:** меньше шума, выше конверсия в скаринг, экономящееся время команды.

## 🚀 Для кандидатов: пора применить AI там, где он реально нужен

Мы внедряем ИИ в код, в аналитику, в продажи, в поддержку. А поиск работы до сих пор делаем вручную:
- Руками ищем вакансии
- Руками копируем шаблоны
- Руками прикрепляем (и забываем прикрепить) письма
- Руками проверяем: «А прочитали ли моё?»

**Парадокс:** самый важный «проект» в карьере — поиск следующей роли — мы делаем без инструментов.

Этот бот меняет правила:
```
/hh-search "iGaming PM" 300000 7    → находит 300+ вакансий за секунду
/hh-apply 134646797                   → откликается С письмом за 30 сек
/hh-verify 134646797                  → гарантирует: письмо на месте
/hh-negotiations                      → все чаты с рекрутерами в одном месте
/hh-cv-design split                   → PDF-резюме (split layout) в TG
```

## ⚙️ Как это работает под капотом (без магии, с инженерной честностью)

**Playwright + Chromium** — единственный способ пробить hh.ru из-за границы (системный python в sandbox, exit code 49).

**Magritte UI (новый дизайн hh.ru 2024):**
- Toggle «Добавить сопроводительное» создаёт *новый* textarea → дельта по индексам
- Non-breaking space (`\xa0`) в «Вы\xa0откликнулись» → нормализация body перед парсингом
- Автосохранение на blur → `Tab` + `wait 7s` + **обязательный reload для верификации**

**Telegram API:** PowerShell 5.1 ломает кириллицу → `curl.exe` с UTF-8 JSON файлом.

**Chat-fallback:** если кнопка «Прикрепить» багует (часто) → бот заходит в конкретный чат на chatik.hh.ru и шлёт письмо сообщением. Работает 100%.

## 💡 Философия: автоматизация ≠ спам

> **Автоматизация без верификации = генератор багов в продакшн.**  
> **Автоматизация с верификацией = надёжный пайплайн.**

Каждое письмо — уникальное. Каждый отклик — проверенный. Никакого «откликаюсь на всё подряд».

Это инструмент для **Senior/Lead ролей**, где цена ошибки высока, а конкуренция — за качество, не за количество.

## 🤝 Открыт для сотрудничества
